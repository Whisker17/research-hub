背景动机

问题：被动 AMM 的报价只在有人交易时才动。外部价格一变，套利者先吃掉旧报价，LP 承担 LVR。论文测得 AMM 成交后 2 秒亏 0.22–2.06 bps（F1）。

为什么现在：propAMM 已是主流成交场所。到 2026 年，它在 Solana SOL/USDC 上的成交超过一半。Base 和 Monad 上的份额仍在上升。Mantle 正在设计自己的 RFQ / propAMM 与 Router，需要知道这些场所靠什么赚钱、谁在付钱。

论文定位：

  • 不是 SoK。它的贡献是一手数据：3 条链、2025-09-01 至 2026-08-31 的成交、更新和 Bybit 订单簿。
  • 它逆向了闭源合约：Tessera 完整还原，Metric 和 Elfomo 部分还原。
  • 它把行业传闻（按对手定价、spoofing）变成可检验的数字。

范围：Solana SOL/USDC、Base ETH/USDC、Monad MON/USDC。非目标：以太坊主网 propAMM（作者认为依赖 builder 排序，更像 RFQ）、链上订单簿（如 Kuru）、长尾资产。

B-0

逆向选择与 LVR（loss-versus-rebalancing）

~4min
是什么

外部价格变了而报价没变，套利者先吃掉旧报价。LP 因报价过期而亏的部分叫 LVR。

为什么这里需要

propAMM 的设计目标就是消除 LVR：不等交易，直接改价。

最小例子
Bybit：2,457.46 → 2,457.79
AMM 仍按 2,457.46 卖
套利者每 ETH 赚 0.33 USDC
≈ 1.3 bps，由 LP 承担
常见误解

误解：LVR 就是无常损失。事实：LVR 只计算报价过期被套利的部分，不和"持币不动"比较。

B-1

markout（成交后盈亏）

~4min
是什么

成交后 τ 秒，用参考价重估这笔成交，得到做市方的盈亏。正数表示做市方赚。

为什么这里需要

论文的所有结论都用 markout 表达。Mantle 可以直接把它用作做市商 KPI。

最小例子
做市方卖 1 ETH @ 2,457.50
2 秒后 microprice 2,457.25
markout = 0.25 / 2457.25
       ≈ +1.0 bps
常见误解

误解：markout 为正就是净利润。事实：论文报告的是 gross 值，没有扣 gas、对冲和库存成本。

B-2

propAMM（proprietary AMM）

~6min
是什么

链下定价引擎加链上合约。引擎持续计算公允价，用很小的交易写进合约。合约用运营方的库存按这个价格成交。

为什么这里需要

Tessera、Metric、Elfomo 都是这个结构。Mantle 的 Fluxion 要做同样的设计选择。

最小例子

Tessera 一次价格更新只写 25 字节：序号、参考区块、锚定价、价差。实测消耗 26,702 gas，详见"Tessera 逆向细节"面板。

常见误解

误解：propAMM 就是 RFQ。事实：RFQ 每笔报价单独签名给一个 taker；propAMM 的报价是链上状态，任何人都能直接调用成交。

B-3

区块内排序与 Flashblocks

~5min
是什么

排序器决定区块内的交易顺序。Base 按单位 gas 优先费排序，并每 200 ms 发出一个子区块（Flashblock）。

为什么这里需要

改价必须排在 taker 前面才有效。spoofing 也利用块首与块末的时间差。

最小例子

Base 区块 2 秒，最多 10 个 Flashblock。论文测得 propAMM 成交量集中在 FB1 和 FB10，合计 45.71%。

常见误解

误解：出价最高就排第一。事实：Flashblock 广播后顺序锁定，后到的高费交易只能进下一个 Flashblock。

B-4

聚合器按快照路由

~5min
是什么

聚合器在链下读取某一时刻的链上状态，模拟各场所的输出，再把路由写进用户交易。

为什么这里需要

快照时刻和成交时刻之间，状态可以被改。论文的 spoofing 和 Router 建议都围绕这个缺口。

最小例子

聚合器读区块 N 末尾的 Tessera 状态（默认费 0）。用户交易落在区块 N+1 中段，此时默认费已是 538 ppm。

常见误解

误解：滑点保护能挡住 spoofing。事实：差额小于滑点容忍度时，交易照样成交，用户只是拿得更少。

M

发现

F1

propAMM 成交后为正 markout，AMM 为负

置信度: high
论断

成交后 2 秒，propAMM 在 Solana、Base、Monad 分别赚 0.37、1.19、1.69 bps。AMM 分别亏 0.22、0.62、2.06 bps。曲线形状相反：AMM 成交前在价内、成交后亏；propAMM 成交前在价外、成交后赚。

证据

observed 论文 §6，图 3、图 4，参考价为 Bybit microprice。observed AMM 亏损幅度与波动率同序：ETH 60%、SOL 66%、MON 123%。

影响

propAMM 确实避开了大部分 LVR。Mantle 的做市商 KPI 应包含 markout 曲线（−5 s 到 15 s）。

F2

改价比 swap 便宜一个量级，做市商只在关键时刻付优先费

置信度: high
论断

Base 上一次改价中位约 2.7 万–3.3 万 gas，一笔 swap 约 20 万–40 万 gas，便宜 5–15 倍。Tessera 每 0.563 个区块改价一次，改价次数与 ETH 波动率的相关系数为 0.56。

证据

observed 论文 §7.1。observed 我们在 Base 上读到一次价格更新 gasUsed = 26,702，论文中位数 26,706。observed 21,000 gas 的交易底价占改价成本的大头。

影响

在 EVM 链上做 propAMM，改价载荷要极小。Mantle 的优先通道可以替代"用优先费抢位置"。

F3

propAMM 按交易对手定价

置信度: high
论断

Solana 前 6 家 propAMM 中，5 家给非聚合器流量更宽的往返价差（68%–83% 的对比格，p < 0.001）。溢价从 0.10 bps（BisonFi、Tessera）到 3.59 bps（GoonFi）。Tessera 上白名单地址实际成本 0.78 bps，加罚地址 4.96 bps。

证据

observed 论文表 1 与 §7.2。observed Tessera 同时检查 tx.origin 和直接调用它的合约（附录 C.2）。

影响

Mantle 的 Router 合约地址会被做市商打标签。白名单资格会被所有经过 Router 的流量共享，包括套利者。

F4

Tessera 的利润主要来自罚金，而不是订单簿价差

置信度: high
论断

按成交量加权，名义成本 0.44 bps，含罚金 1.95 bps。单笔成交（占 20.70% 成交量）在 2 秒时 markout +1.29 bps；去掉罚金约 −1 bps。默认费只出现在 22.7% 的交易上，却贡献 56.2% 的罚金收入。

证据

observed 论文 §7.2、§7.3、图 6、附录 C.1。observed 优先费罚金最常见（42.7% 的交易），恰好 2 bps 和 5 bps 两个峰几乎全由它构成。

影响

订单簿报价不能代表实际成本。Mantle 若要求 propAMM 公开罚金分量，用户和 Router 才能比较真实价格。

F5

跨场所原子套利中，已改价的 propAMM 是赢的一方

置信度: medium
论断

propAMM–DEX 套利占 propAMM 成交量的 5%（Solana）、13%（Base）、6%（Monad）。propAMM 这一腿接近持平或为正；未改价的一方亏损。Tessera 对其他 propAMM 的套利中，对手方 2 秒后约 −0.5 bps。

证据

observed 论文表 2、图 6(b)、图 18。inferred 套利前参考价已移动 1.9–7.3 bps，说明套利修正的是旧报价。

影响

Mantle 引入 propAMM 后，Agni、Merchant Moe 等 AMM 的 LP 会更多地成为亏损的一边。

F6

spoofing：只有 39% 的交易按聚合器看到的报价成交

置信度: high
论断

Tessera 的默认费上调集中在区块前 10%，下调集中在后 10%。交易平均比块末报价差 1.08 bps，按成交量加权差 0.56 bps。区块 50,196,022 中，默认费 0 → 538 ppm 把含费价差从 2.78 bps 拉到 13.54 bps。

证据

observed 论文 §7.4、图 7、图 11、表 3。observed 0x 独立报告：某 propAMM 的最后一次改价 97.4% 落在最后一个 Flashblock，块内价格方差是块间的 5–7 倍 [4]。observed 我们在两个区块中都看到默认费更新"块首一次、块末一次"，详见"Tessera 逆向细节"面板。

影响

交易内询价的 Router 能让选路基于真实价格。费率类参数还要靠排序器或合约层约束。见"对 Mantle 的意义"面板：排序器 S1、合约规范第 4 条。

F7

散户在 propAMM 上付得更少

置信度: medium
论断

安静成交（参考价 6 秒内变动 < 1 bp）在 propAMM 上付 0.26 / 1.26 / 1.62 bps，在 AMM 上付 2.59 / 1.38 / 8.60 bps（Solana / Base / Monad）。安静成交占 propAMM 成交量 32% / 43% / 17%，占 AMM 只有 9% / 16% / 8%。

证据

observed 论文 §8、图 8、附录 G。inferred "安静成交 = 散户"是近似，论文没有身份数据。

影响

"比 AMM 便宜"可以作为 Mantle propAMM 的对外卖点，但要和 F6 的 spoofing 数据一起看。

F8

Tessera 的改价交易是 25 字节载荷，由多个地址并发提交

置信度: medium
论断

价格更新不走 ABI 函数，calldata 只有 25 字节：1 字节序号、5 字节参考区块、16 字节锚定价、3 字节价差。多个 EOA 同时提交，新序号排在前面，旧序号随后 revert（约 2.4 万 gas）。

证据

observed Base RPC 读取区块 50,369,777 和 50,196,022，命令见"复现"面板。inferred 字段划分由数值反推：价格 2,457.788 与价差 45 ppm 和论文图 1 一致。inferred 优先费尾数随序号递增，所以同一 Flashblock 内新报价先执行。

影响

Mantle 优先通道可以丢弃同一做市商的旧更新。这样就省掉并发 revert 消耗的 gas。

和论文不一致的一点

论文说 Tessera 改价时付 2.37 倍 base fee。我们的两个区块里，改价交易只付 0.1–0.68 倍。样本只有 2 个区块，不能据此否定论文的中位数。默认费参数打包在一个 32 字节字里，我们没有解出 538 ppm 的编码。

附录 C.1 的两个公式怎么来（Φ = Σϕ / 10⁶）：

  • 实际卖价 = p_a / (1 − Φ)，实际买价 = p_b · (1 − Φ)。代入半价差公式，分子分母同乘 (1 − Φ)，得到 c_eff = 10⁴ · (p_a − p_b(1−Φ)²) / (p_a + p_b(1−Φ)²)。
  • 用户拿到 Y = Y_book · (1 − Φ)。所以 Y_book = Y / (1 − Φ)，第 k 项扣下 Y_book · ϕ_k / 10⁶ = Y · ϕ_k / (10⁶ − Σϕ)。

对 Mantle 的意义

Mantle 的计划见 [12]，包含以下组件：

  • Fluxion RFQ 与 propAMM，Bybit W2 做市库存
  • 单排序器，无公开 mempool
  • 做市商撤单优先通道，200 ms 预确认
  • 接入 OKX / Kyber / LI.FI 聚合器

你还提到 JIT Router，以及把做市商改价放进预确认。下表把论文的每个发现映射到这些组件。

论文发现 JIT Router propAMM / RFQ 排序器
F2 改价便宜 — 紧凑载荷 优先通道只放价格更新
F3 按对手定价 Router 地址会被打标签 公开分类规则 —
F4 罚金决定成本 用实际输出比价 罚金分量可查询 —
F5 跨场所套利 — — AMM LP 风险上升
F6 spoofing 交易内询价 费率延迟生效 费率更新不进优先通道
F8 并发提交 — 序号作废 丢弃旧更新

JIT Router

  1. 在交易内调用每个场所的 quote()，再按实际输出选路。论文 §9 和 Jump [5] 都给出这个建议。以太坊上的 Lambda Class Router 已用 IPropAMM 接口实现 [7]。
  2. 要求 quote() 和 swap() 使用同一套罚金逻辑。在 Router 里断言成交不低于报价，否则回退到下一个场所。
  3. 预先和做市商约定 Router 的身份规则。不要让 Router 整体进白名单；做市商仍会按 tx.origin 分类（F3）。
  4. 给 Fluxion RFQ 留入口：调用方把 EIP-712 签名报价放进 calldata，Router 在同一交易内和 propAMM 报价比较。
  5. 上线前测量 quote() 的 gas。论文只测了 swap（Base 上 20 万–40 万 gas），没有测询价。候选场所数要设上限。
  6. 用事件记录每笔的报价与成交。用它计算报价—成交一致率，对标 Tessera 的 39%。

propAMM 合约规范（Mantle 对做市商的要求）

  1. 用"锚定价 + 价差 + 档位倍数"的状态，改价只写一个存储字。
  2. 记录参考区块，设宽限期和过期。即使有优先通道也保留它，用来应对排序器故障。
  3. 通过 quote() 返回罚金分量，并在事件里公开。论文作者必须逆向才能拿到这些数据。
  4. 默认费等费率参数的变更延迟到下一区块生效。这样聚合器读到的块末状态就是下一块的真实费率。
  5. 如果 Mantle 的排序不按优先费拍卖，就没有理由收优先费罚金。需要先确认排序规则。
  6. RFQ 报价有效期 5–15 秒（见 [12]），比 Tessera 的报价寿命长得多。考虑改为按区块计的有效期，并按报价年龄加价。

排序器与预确认

  1. S1 优先通道只放行价格类更新：p、s、序号作废。费率、白名单、黑名单更新走普通通道。
  2. S2 同一做市商的旧更新直接丢弃，不上链。Titan 在以太坊上就是这样做的 [8]。
  3. S3 私有 mempool 对做市商也必须私有。做市商不能看到待处理的 taker 交易。
  4. S4 子区块预确认会重现 0x 记录的"块末诱饵"问题。Router 交易内询价可以缓解，费率延迟生效可以消除。
  5. S5 评估 Agni、Merchant Moe 等 AMM 的 LP 风险。可以考虑动态费或预言机保护。
CAUTION：不要把费率更新放进优先通道

Tessera 的 spoofing 只需要两笔默认费更新：块首上调，块末复位。优先通道会保证这两笔每次都准时落地，把 spoofing 变成稳定行为。

WARNING：优先通道 + 可见的 taker 流 = last look

如果做市商能看到排序器里的 taker 交易，再用优先通道撤单或改价，就构成 last look。用户按报价下单却拿到更差的成交，且链上无法证明。Bybit W2 是关联方，这条规则必须公开并可审计。

监控与 KPI

  • 复用论文方法建仪表盘：markout 曲线、安静 / 非安静拆分、聚合器与非聚合器的往返价差、报价—成交一致率。
  • README 里的 KPI "价差 ≤ 3–5 bps" 是报价价差。建议增加"含罚金的实际成本"和"报价—成交一致率"。

局限与开放问题

论文没有证明什么

  • 没有证明 propAMM 净盈利。markout 不含 gas、对冲和库存成本。
  • 没有证明 spoofing 是有意的。块首加费也可以解释为防御：区块开头最容易遇到抢跑。
  • 没有覆盖 RFQ。Mantle 的 Fluxion 是 RFQ + propAMM 混合，结论要部分迁移。
  • 散户结论依赖"安静成交"这个近似。

我们这次的局限

  • 链上抽查只有 2 个区块。优先费倍数与论文不一致（见 Tessera 逆向细节）。
  • Mantle 的事实来自仓库文档 [12] 和你的描述，没有链上核实。

复现

需要 Foundry 的 cast 和 Python 3。所有命令只读，使用 Base 公共 RPC。

在 Mantle 上算 markout（步骤）

  1. 解码目标池的 swap 事件，记录区块、交易位置、方向、数量。
  2. 给每笔成交定时间戳。有预确认流时，用子区块的接收时间。
  3. 取 Bybit 订单簿，计算 microprice。
  4. 对 τ ∈ {−5, …, 15} 秒计算 markout，按名义金额加权平均。
  5. 按"安静 / 非安静"和"单笔 / 套利"分组重复第 4 步。
S

术语表

LVRloss-versus-rebalancing
报价过期被套利导致的 LP 损失。它按"与持续再平衡的组合相比"计算。不是无常损失
markout成交后盈亏
成交后 τ 秒用参考价重估这笔成交，得到做市方的盈亏，正数表示做市方赚。论文中是 gross 值，不是净利润
propAMMproprietary AMM，专有 AMM
运营方用小交易直接改价、用自有库存成交的链上合约。不是 RFQ，报价是链上状态
RFQrequest for quote
做市商对单个 taker 签发一次性报价，taker 带签名上链成交。报价不是链上公共状态
锚定价anchor price, p
Tessera 存储的单一参考价。所有档位按倍数相对它定位。不是成交价
罚金penalty, ϕ
Tessera 在走完梯子后扣下的输出比例，由 6 个分量相加，单位 ppm。不是 LP 手续费
默认费default fee
Tessera 罚金分量之一，运营方可随时改，白名单地址免收。论文观测到它在块首上调、块末复位
Flashblocks子区块预确认
Base 每 200 ms 发出一个子区块，广播后顺序锁定。不是最终确认
预确认preconfirmation
排序器在区块最终确认前给出的执行承诺。通常只是运营承诺，没有密码学保证
microprice加权中间价
按对侧挂单量加权的买一、卖一中间价。不是简单中间价
原子套利atomic arbitrage
一笔交易内在两个场所反向买卖，所有代币余额变化都不为负。不是 CEX–DEX 套利，后者有链下腿
往返价差realized round-trip spread
同一池子相邻两笔反向、规模相近成交之间的相对价差。不是报价价差
安静成交quiet fill
成交前 5 秒到后 1 秒，参考价变动小于 1 bp 的成交。论文用它近似散户。不是身份识别
spoofing诱饵报价
快照时显示好价格，成交时给更差价格。论文用于描述 Tessera 的默认费模式。不同于传统市场的挂单撤单式 spoofing
last look最后一看
做市商看到 taker 订单后再决定是否按报价成交。不是撤单优先本身
JIT Router交易内询价路由
在同一笔交易内询问各场所报价，再在最优场所成交的路由合约。不是 JIT 流动性
